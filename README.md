# Purba Medinipur Matsyajibi Forum — website

Static website. No build step.

## Publish on GitHub Pages
1. Create a new repository (e.g. `pmmf-website`).
2. Upload **all files and the `leaders` folder** from this folder to the repository root (keep the same structure).
3. Repository → Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / root → Save.
4. After about a minute the site is live at `https://<your-username>.github.io/pmmf-website/`.

## Files
- `index.html` — the website
- `pmmf-content.js` — all text in English and Bengali (edit here to change words)
- `support.js`, `image-slot.js` — required runtime, do not delete
- `dmf-logo.png`, `leaders/` — logo and office-bearer photos

## Notes
- Some photos load from the client's Google Drive folder. Keep that folder shared as "Anyone with the link", or replace those photos with local files.
- Demands and news items are still demo text.
